## 🎨 Visual System & Themes — Visual Fusion

- **Visual Fusion Design System:**
  - Multi-spectrum hyper-gradients combining Electric Cyan (`#06b6d4`), Cyber Violet (`#8b5cf6`), and Neon Coral (`#ec4899`).
  - Cosmic Obsidian glassmorphism surfaces (`#070913`, `#0d1224`) with glowing translucent edge highlights.
  - 4 Floating atmospheric fusion orbs with organic drift animations.
  - Interactive HTML5 `<canvas id="bgCanvas">` particle network featuring multi-hued fusion nodes and mouse-reactive connective webs.
- **Theme Switcher:**
  - **Dark Mode ("Cosmic Fusion" - Default):** Deep obsidian night accented by electric cyan, cyber violet, and hot coral radiant glows.
  - **Light Mode ("Porcelain Fusion"):** Luminescent ultra-clean glass canvas with vibrant chromatic gradient accents.
  - Interactive toggle button in the navbar with localStorage persistence and toast notification.
- **Typography:**
  - Primary UI & Headings: `Plus Jakarta Sans` & `Inter`
  - Code & Mono badges: `Fira Code`
- **Iconography:** FontAwesome 6.5.1 CDN
- **Dynamic Elements:**
  - Dual-ring orbiting avatar with pulsing glow dots (`.avatar-orbit`).
  - Smooth typewriter title animation rotating functional roles.
  - Animated stats counter triggered on scroll via `IntersectionObserver`.
  - Dynamic skill level bars with smooth percentage expansion.
  - Category filter tabs for Skills and Projects.
  - Project detail modal popup (`.modal-overlay`).
  - Scroll progress bar at the top (`#scrollProgress`).
  - Toast notification engine (`#toastContainer`).
